# 🐾 PetAdoption – Дом для каждого питомца 

## 🌟 О проекте
PetAdoption – это платформа для
поиска и усыновления домашних
животных, связывающая приюты и
потенциальных владельцев.

**Основные возможности:**
- 🐶 Просмотр анкет животных из приютов-партнеров
- ❤️ Система избранного для сохранения понравившихся питомцев
- 📍 Поиск животных по локации, возрасту и другим параметрам
- 📱 Удобный интерфейс для приютов и волонтеров

Технологии
------------

1) Apache WebServer<br>
2) PHP 8.3+ (Yii 2.0.52)<br>
3) MySQL 8.0+ / MariaDB 10.8+

## 🚀 Быстрый старт

### Установка
Заполните данные для подключения к бд в `config/db.php`:

```php
...
'dsn' => 'mysql:host=localhost;dbname=<ИМЯ_БД>',
    'username' => '<ИМЯ_ПОЛЬЗОВАТЕЛЯ>',
    'password' => '<ПАРОЛЬ_ПОЛЬЗОВТЕЛЯ>',
...
```

Затем, выполните миграции:

~~~
yii migrate
~~~
